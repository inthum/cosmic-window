# cosmic-window

A calm procedural cosmic scene for the web.

## Purpose

`cosmic-window` is a visual web piece designed to feel alive, dark, calm and spatial without becoming chaotic or tiring.

It is intended as a public-facing project: a small but serious visual experiment that represents aesthetic control, atmosphere and technical sensitivity.

## Status

Public MVP.

- `index.html` — standalone visual scene

## Notes

This project is intentionally minimal and focused.
Future changes should remain small and controlled.
